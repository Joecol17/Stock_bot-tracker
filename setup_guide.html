🔑 Where API Keys Go

📌 Trading 212 API Key

What it is: Your authentication token for Trading 212 API

Where to get it:

  1. Go to https://trading212.com
  2. Create an account or log in
  3. Go to Settings → API
  4. Generate or copy your API key
  5. Keep it secret! Never share it

🖥️ Where to Set It (Windows)

Option 1: Temporary (Current session only)

Open PowerShell and run:

$env:TRADING212_API_KEY = "your_actual_api_key_here"

Option 2: Permanent (Recommended)

  1. Right-click This PC → Properties
  2. Click Advanced system settings
  3. Click Environment Variables button
  4. Under "User variables" click New
  5. Variable name: TRADING212_API_KEY
    Variable value: your_actual_api_key_here
  6. Click OK three times
  7. Close and reopen your terminal/PowerShell

✅ Verify It Works

Open PowerShell and run:

$env:TRADING212_API_KEY

If set correctly, it will display your API key

⚡ Quick Start (5 Minutes)

Step 1️⃣ Set Your API Key

In PowerShell:

$env:TRADING212_API_KEY = "your_api_key_from_trading212"
✓ Tip: Make this permanent in System Environment Variables to avoid setting it every time

Step 2️⃣ Start Ollama

Install Ollama first:

Download Ollama

Then run in a terminal:

ollama serve

In another terminal, download the model:

ollama pull llama2
✓ Keep this running while you use the trading system

Step 3️⃣ Run the System

Run demo:

python main.py

Or try interactive mode:

python interactive.py

Or start automated bot:

python auto_trader.py

⚙️ Configuration Variables

Set these environment variables to customize the system:

Variable Default Purpose Example
TRADING212_API_KEY *(required)* Your Trading 212 API key abc123xyz...
TRADING212_DEMO_MODE true Use demo account (true/false) true
OLLAMA_MODEL llama2 Ollama model name llama2
OLLAMA_TEMPERATURE 0.2 Decision consistency (0-1) 0.2
DEFAULT_TRADE_QUANTITY 1 Shares per trade 1
MAX_DAILY_TRADES 10 Maximum trades per day 10

Set in PowerShell:

$env:TRADING212_DEMO_MODE = "true" $env:OLLAMA_MODEL = "llama2" $env:DEFAULT_TRADE_QUANTITY = "1"

🔧 Troubleshooting

API Key Error

Problem: "TRADING212_API_KEY environment variable is required"

Solution:

$env:TRADING212_API_KEY = "your_api_key"

Ollama Not Found

Problem: "Ollama query failed"

Solution:

ollama serve

Run in another terminal

Model Not Found

Problem: "Model llama2 not found"

Solution:

ollama pull llama2

Connection Error

Problem: "API request failed"

Solution:

  • Check internet connection
  • Verify Trading 212 API is up
  • Check firewall settings

Insufficient Funds

Problem: "Insufficient free funds for trade"

Solution:

  • Check account balance
  • Ensure demo mode is ON
  • Reset demo account

No Positions

Problem: "No open positions"

Solution:

  • You haven't bought anything yet
  • Run a trade using interactive.py
  • This is normal for new accounts
